# Native evaluation preparation

Frozen axis examples cover arithmetic composition lengths 2/4/8, repeated physical
updates, and physics values outside the primary curriculum. evaluate_episode feeds
original predicted carries/velocities forward and records independent reference
errors afterward. It never resets a wrong prediction to the reference.

transfer_preparation copies explicitly listed shared-core tensors while retaining
identical target initialization heads and records disjoint exposure identities.
This prepares a comparison; it does not execute transfer training or verify transfer.
Independent task rows reset working memory; only explicitly linked episode identities
may retain detached state. Statistical helpers provide paired bootstrap intervals
and Holm adjustment, but no measured neural superiority is claimed.
