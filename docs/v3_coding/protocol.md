# Frozen coding-learning protocol v1

Source, generated benchmark and controlled comparison froze at commit `38a8494`, before any new-benchmark Qwen evaluation. Machine-readable plan: `configs/v3_coding/protocol.json`. The public manifest hash is `cbf14a799b6c8575923fa34a4be6189ebc818da32ff35c18b432c92c4f6743f6`.

There are 24 training, 6 validation, 6 IID and 12 structural-OOD tasks, with six OOD families and two tasks per family. Every defective and reference repository was independently executed against both its visible and private suite. Both defects must fail, both references must pass. One empty-input generator initially lacked a private failing case; actual pre-freeze validation caught it and the generator was corrected before freezing. No model result chose task difficulty.

OOD families: cross-file dependency contracts, compound predicate/accumulator bugs, while-loop control flow, identifier renaming, alias mutation through a helper and order/boundary composition. These are bounded synthetic Python tasks; unfamiliar syntax and composition are not broad real-repository generalization. Names and numerical parameters are seeded. Canonical public task identities are disjoint; familiar templates/local mechanisms deliberately repeat. Unknown foundation pretraining contamination is not ruled out by synthetic identity checks. Renaming is combined with fresh task parameters, not a perfectly isolated rename contrast.

All candidates are proposed by the pinned local Qwen2.5-Coder-1.5B-Instruct. Same greedy CPU float32 backbone, same maximum two calls of 256 new tokens, up to two candidates per call and up to four existing-file replacements per selected action. All conditions observe the initial real visible failure and every accepted edit's visible results. Stop on visible pass or call cap. Private outcomes never determine another model call, edit or memory update. Private scoring and first-edit scoring occur only after the learner terminates. Visible pass is not private success.

Compare plain, structured, typed tools, Mindscape, no-memory, no-planning, no-concepts and word-overlap memory. Plain/structured/typed receive two fixed approved training examples from the same 24-example pool; memory conditions retrieve two. No-memory removes runtime examples, and no-concepts replaces structural retrieval with words and zeros structural evaluator inputs. These are practical inference interventions, not perfectly equal-token architecture-only contrasts. No-planning retains prompts/weights and selects candidate zero. The typed baseline shares the mandatory tool loop and explicit tool schema. Plain/structured differ in redundant structured-contract framing; even plain receives the function contract, source and visible feedback. Model-output parsing never replaces a proposal with a reference patch or silently repairs a filename.

The new evaluator is a 3,682-parameter two-head neural network. Train 400 updates, seeds 11/23/37, on 96 labeled proposals from 24 distinct training tasks: actual teacher edits, no-ops, invalid syntax and wrong constant-return candidates. Usefulness means actual **visible-test** success, not private correctness. Cost labels are measured WASI duration (zero for pre-execution rejection). Training representations use leave-task-out retrieval. No new Qwen LoRA update is claimed. Existing adapters remain immutable.

Primary: exact terminal private structural-OOD success, target at least 60% plus a meaningful paired improvement over the strongest fair baseline on **this** benchmark. Report family counts, first-edit correctness, self-correction, false visible repairs, parse failures, logical model calls, actual VM calls, fresh tokens, latency and visible-outcome calibration. Retain every failure. Wilson and paired task-bootstrap intervals are descriptive for this tiny fixed sample; shared cached requests are not fresh latency or independent LM seeds. Gradient seeds concern the evaluator, not the fixed greedy backbone.

Resource policy: MPS unavailable in this execution environment. Observe actual CPU feasibility first, then run bounded 1,800-second invocations and resume saved keys without resampling failures. A cap receipt is explicit partial coverage, not a completed benchmark. Source, manifests, training snapshots, backbone hashes and raw trace hashes bind resume. Exact identical prompts can reuse saved real model responses; fresh-token accounting is zero on cache hits. Retain invocation receipts to count actual total compute. Independent replay runs WASI without neural inference.

Historical B=48% and C=36% belong to the old 50-task OOD lockbox. Audit saved result traces only; do not open or retune that lockbox. Do not compare those percentages with new-benchmark percentages. Historical adapter reruns, if performed, are separately labeled bridge diagnostics, including any budget or evidence mismatch. The predeclared primary comparison uses same-backbone new conditions.
