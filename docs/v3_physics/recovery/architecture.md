## Environment and observation boundary

Pinned Pymunk7.2.0/Munk2D2.0.1 revade7ed… is authoritative CPU simulation. Every step uses four substeps at1/120s, gravity, body forces/impulses, circle contacts, material friction/restitution and optional damped spring constraints. Motion scenes include projectiles/floor contact and OOD multi-object encounters; interaction scenes include elastic/inelastic mass-dependent collisions and spring coupling. The floor is the obstacle; arbitrary maze navigation is not implemented. Geometry is bounded to at most three circular bodies.

Public values contain position, velocity, visible mass/materials, radius, contact and active-object flags, plus masks, permitted gravity/spring/time context and known actions. Hidden mass/friction/restitution are zeroed with missing masks. Some scenes omit velocity sensors; history remains available. Sensor noise is seeded independently per scene/time. Private scene records and exact future states live only in preparation/scoring; prediction receives a strictly checked four-key dictionary. Held-out future actions are known controls, not an answer from the simulator.

The1000-scene dataset has250 train,50 validation,100 IID and100 OOD scenes per family. Nested budgets select prefixes of frozen training IDs. Temporal frames are correlated labels, never independent episodes. OOD round-robins mass/friction, velocities, longer horizons, new object configurations, noise, changed parameters and interaction composition. Exact scene identities are disjoint, while local mechanisms intentionally recur. Dataset hashes and manifest hashes protect integrity; they do not prove authenticity if an attacker rewrites all receipts.

## Neural architecture

The MPS-only shared object encoder consumes four history frames and masks, known actions and context. Derived representations summarize relative displacement/velocity/distance/approach, observed finite-difference velocity/acceleration and momentum when mass is visible. These are deterministic observable features, not physics execution or hidden next states. Relational pooled object embeddings condition a next-state-delta, Gaussian log-variance and contact head. Parameter inference is history-conditioned latent response and evaluated acceleration proxies; no calibrated direct hidden-mass/friction estimator is claimed.

All neural variants have the same parameter dimensions and400 updates. Matched zeroes added relationships/concepts/pooling and excludes episodic residual correction; all variants receive the same transition targets and visible inputs. Single-component variants zero relationships/concepts, omit memory, or collapse history. The no-feedback negative control permutes dynamics labels; it explicitly changes supervision and is not an architecture-only ablation. A maximum256 approved training transitions provide top-three residual memory correction at fixed coefficient0.1. Memory derives from frozen actual simulation transitions and cannot admit evaluation outcomes. Uncertainty is aleatoric diagonal Gaussian; accumulated variances ignore temporal correlation and are not an epistemic guarantee.

The domain adapter serializes shared V3 Observation/Entity/Relationship/Concept records. Continuous force/impulse vectors use separate typed records rather than altering the preserved integer-action kernel. Prediction and actual execution remain separate. A bounded planner evaluates nine hypothetical impulse trajectories, chooses a declared distance/risk/penetration objective and then independently executes only its selected action. Actual goal attainment uses terminal distance≤0.75; avoidance additionally requires no contact. Planning records model candidate rollouts and actual simulator steps. Random/simple/analytical controls and a separate MPS model-free policy are supported. The model-free policy receives additional training-only action labels from nine actually executed alternatives, so it is not an equal-information dynamics comparator.

## Durability and validation

Atomic generation checkpoints include model weights, Adam state, scales, memory and exact progress. A hash-bound index commits the new generation only after writing it; an interrupted write leaves the prior generation resumable. Sampling uses a deterministic update-index seed, and the native integration test compares interrupted/resumed versus uninterrupted fits. Dataset/source/protocol/seed/budget/variant/update identities guard resume. Source changes demand a fresh run. No-op completed evaluation verifies traces rather than regenerating neural outputs.

The independent verifier reconstructs actual dataset trajectories and selected planning actions on CPU, verifies checkpoint hashes and recomputes prediction metrics without neural inference. Scene-level paired bootstrap and exact cell coverage checks are separate from a driver-finished flag. Validation scenes are frozen and currently unused for tuning. The primary target is at least20% normalized OOD rollout-error reduction versus matched at250 trajectories, with maintained/improved actual planning success. Small synthetic settings do not establish real-world physical understanding.
