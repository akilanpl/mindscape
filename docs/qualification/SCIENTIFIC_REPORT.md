## Forward path and supervision

Actual graph observations contain typed node features, observed action, concept IDs,
relations, domain and legitimate requested rename instruction features. Targets are
not passed to the graph encoder. Domain losses reach the very same feature/message/
concept parameters; measured nonzero-gradient tensor intersections are in receipts.
Shared gradients establish shared parameter use, not positive transfer.

Math digit/carry logits and physical deltas are genuine learned-parameter outputs;
exact references are used only for supervision or post-prediction verification.
The addition controller supplies least-significant-digit traversal and feeds its own
predicted carry forward. That scaffold is not learned planning. Coding predicts a
candidate identifier and applies a deterministic AST rewrite; this is NOT code
transformation synthesis, semantic program repair, or verified behavioral equivalence.
The action-score head is untrained by the current domain losses. Its selection is
not a qualified learned controller.

## Controls, memory and compute

Original MLP/RNN/GRU receive the same observable feature/type/edge/action/domain/
concept information, represented as tokens. Architectural pooling/sequence biases
remain different and must be described. Actual counts: graph44,962; MLP/RNN45,022;
GRU44,744 (<0.5% count gap). Active parameter use differs; equal totals do not imply
matched effective capacity or FLOPs. Gradient and estimated optimizer storage are
measured, not advertised as process peak memory.

CPU forward/backward timing is recorded by domain/control, with one warmup and
three measured passes, one thread, and unchanged weights. It includes token/graph
packing consistently and constructs no optimizer. Diagnostic scalar losses use all
heads, not campaign task losses; projected2000-pass times are NOT training runtime.
RNN/GRU cost grows with token sequence length. The result explicitly does not claim
compute parity. Full authorized campaign must log real per-update time, process RSS,
loss, examples, repeated samples and inference work separately.

Independent rows have no episode_id and memory resets each time. The recurrent
arm also uses fusion parameters while the stateless arm bypasses them. Therefore
this72-fit proposal cannot isolate a learned long-term memory benefit. A separately
reviewed episodic curriculum/control amendment is required, without silently
reducing/replacing the reserved72fits/144000updates. No existing historical workload
is shortened. General learned transfer requires a separately reviewed source/target
exposure schedule; shared core-only initialization is preparation, not evidence.

## Language audit

StageB has18 synthetic training examples, not general language supervision. All
held-out surfaces are distinct, but slot schemas are reused. Paraphrases reuse operand
families. Reordered structures change syntax and operand combinations. Vocabulary
shift introduces unknown tokens collapsed to <unk>, so ambiguity and copying must
be distinguished from semantics. Receipt counts quantify OOV tokens per split.
Report intent accuracy, present-slot extraction, null-slot extraction and whole-task
exactness separately; aggregate null slots can inflate a score. No language optimizer
or benchmark was executed. Native production grammar is deterministic and unchanged.

## Statistical and evidence protocol

Keep every original prediction keyed by task/seed/checkpoint/source hashes. Preserve
failures, invalid outputs, loss curves and aborted fits. Select only the fixed final
checkpoint; do not tune on held-out labels. Report data-budget learning curves,
objective domain accuracy, full composition exactness/error by depth, physics error
and OOD slices separately. Never pool physical MSE with classification accuracy.
Pair identical task/seed outcomes; cluster all optimizer seeds of the same independent
family before bootstrap. Paired report rejects repairs/duplicates/mismatched identities.
Use predeclared Holm family, effect direction and thresholds; CI alone is not a
scientific success. Infer neither transfer nor data efficiency from random diagnostics.
