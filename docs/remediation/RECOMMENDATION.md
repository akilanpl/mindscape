## Implemented supplemental repairs

- Concept task now holds numeric state, action and domain fixed while explicitly
  supplied relational context selects different transitions. Conditional-information
  audit measures the empirical context-free Bayes ceiling versus context-informed
  prediction. This makes a context-information question identifiable. It does NOT
  show concepts were discovered, embedding superiority, data efficiency or R5.6
  graph generalization. Embedding and equivalent context-vector paths share exactly
  the same matrix parameters/information and produce equal logits as a control.
  Independent per-example corruptions are not reversible global ID permutations.
- Delayed-cue tasks make the final query observations identical across different
  required answers. Retain/reset/donor-past controls execute identical encoder, GRU,
  fusion and head parameters. Traces expose resets, same-episode gradient retention,
  detached donor states and original-hidden-state feedback. Train/heldout cue/query
  combinations are disjoint; delay shifts0/1/4/8 are separately exposed. This repairs
  a supplemental memory identifiability design, not the reserved non-episodic arm.
- Separate program-output semantics proposal has heldout loop/branch/function
  structures, source-only train vocabulary, bounded independent AST interpretation
  and eight actual WASI crosschecks. All eight agree. Eight illustrative programs
  are not a qualified large benchmark or learned semantic result. The old coding
  candidate-identifier study retains its narrow label.
- Language metrics separately score present/null argument spans, exact whole
  arguments, extraction precision/recall, abstention precision/recall and OOVs.
  Existing curriculum remains bounded intent/argument extraction, not broad language.
- Actual random forward/backward diagnostics report total, active-gradient and
  storage counts plus elapsed samples. Same parameter totals do not imply equal
  active gradients, FLOPs or training cost. No optimizer was constructed.
