# OOD approval and custody gates

All decisions are absent for real science. No real approval record, signer key, protected dataset, prediction seal or result is supplied by this change.

The external authority must separately decide protocol adoption; dataset generation/qualification; numerical adapter freeze; fitting authorization; and sealed final evaluation authorization. All five have distinct purpose and decision identifiers. Fitting additionally requires an independent eligibility certificate. Final scoring requires a separately signed seal-before-label-release receipt, bound to the exact raw ordered prediction hash and ordered identity hash, with a custody event sequence later than final evaluation authorization. Sequence numbers are external signer assertions, not a substitute for independent custody audit.

Every receipt is an Ed25519 signature over canonical JSON containing purpose, all content bindings, configured signer identity, decision id, approval and custody sequence. Trusted public keys are supplied externally and pinned by **(purpose, signer)**; keys from receipt bodies are never trusted. The code includes no production private key or approval creation function. Ephemeral in-memory synthetic test signatures authorize only fabricated fixture commitments. Signatures establish possession of the selected external key, not automatically human identity or independence; selecting/auditing those trust roots is mandatory external work.

All decisions bind protocol hash, source inventory hash, v2 SPEC hash, public input hash, private label commitment, training input hash, training demonstration hash, historical registry hash and qualification hash. Actual training content is rehashed at the native boundary. Arbitrary approved booleans, changed bindings, missing purposes, reused decision ids and bad signatures fail closed before native model construction.

Eligibility combines locally checked public identity separation and exact768/96/216 counts with externally signed semantic evidence hashes. The external certificate must supply evidence for composition novelty, familiar constituent support, cross-split leakage, historical alias auditing, distribution/support analysis and one-draw provenance. The public report gives operation frequencies, sequence lengths and operand digit lengths without computing OOD labels or private intermediate states. Semantic transition support cannot be inferred from public identity disjointness; the custodian must independently inspect/commit that evidence and reject ineligible data. The interface does not pretend that opaque evidence hashes independently reproduce those scientific claims.

One-draw generation has a separate pre-draw request binding protocol/source/numerical-spec hashes, seed520054, full768/96/36 counts, six families and an external unique draw id. Independent signatures authorize protocol adoption, numerical freeze and generation before any draw. This request deliberately does not require nonexistent input/label/qualification hashes. An exclusive fsynced marker consumes the draw attempt; no filtering or redraw occurs. Only after the draw does the custodian commit public inputs, private labels and semantic qualification evidence and issue the fully content-bound postdraw decisions used for fitting/evaluation. No such draw has been called in this sprint. The proposed generator has known distinct number ranges and limited chain support; scientific eligibility remains external and unqualified rather than assumed.

Prediction custody requires every learned/nonprocedural condition, every seed and every ordered task, including failures. Full raw trajectories are sealed via exclusive creation before any reference release. The independent signature binds the seal and release order; changed/reordered/missing/substituted rows fail. Native learned trajectories are independently replayed through the declared scheduler using saved predictions only; altered feedback state, extra/missing calls, output substitutions and incomplete operation stages fail. Train-only memorization and state-transition controls are built from the same released training demonstrations. Procedural references are constructed only after signed label release in the scorer, never passed into campaign execution. The label dictionary is available only to the separate released scorer.

Real host/native qualification remains required; CPU forward/backward tests do not qualify MPS or grant any scientific permission. Dataset eligibility, numerical choice review and native execution readiness are still unresolved human/external decisions.

The prelabel prediction seal covers four conditions only: recurrent, feedforward, memorization and transition lookup. The procedural correctness reference is materialized by the independent scorer after verified label release and is reported as a reference, never a preseal neural prediction. Both fitting access and separate final-evaluation access are required before native campaign work.

Numerical score gates alone return GATES_PASS_PENDING_INDEPENDENT_AUDIT or NO_GO_UNVERIFIED. A separate externally signed independent_metric_audit receipt binds the exact report and raw seal hashes before the final scientific verdict function can return a scientific pass. Neither verdict grants release permission.
