## Coverage boundaries

New complex pathways primarily require explicit JSON schemas. This establishes bounded computational coverage, not unrestricted natural-language understanding. Circuits are passive resistor networks with supplied fixed voltages, not arbitrary active circuits. Fields are 2D vacuum point charges. Induction is average emf from flux per turn; photoelectric output is stopping-potential magnitude above threshold. ODEs are constant-coefficient first-order linear initial-value problems with polynomial forcing. Probability needs explicit event assumptions. Python remains a small interpreter, not full CPython: arbitrary imports, file/network access, attributes, closures and general exceptions remain unavailable. CSV data must be inline. SQL is read-only in-memory SQLite with explicit supplied data, not a live database.

Language-model plans remain advisory and visibly unverified. The final checked answer and worked text are rendered deterministically from the tool result; no second language-model call can rewrite the verified result. Some verification uses the same symbolic engine and is not an independent proof. Benchmark references are separate from application tool checks.
